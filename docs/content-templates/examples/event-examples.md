# Hands-on Workshop: Building Digital Twins with Open Source Tools

## Workshop Overview

This intensive one-day workshop provides hands-on experience in building digital twins using open source tools and frameworks. Participants will learn practical implementation techniques and work through real-world examples.

## Event Details

### Date and Time
- **Date**: April 20, 2024
- **Time**: 9:00 AM - 5:00 PM CEST
- **Duration**: 8 hours (including breaks)

### Location
- **Venue**: Inria Lyon Research Center
- **Address**: 56 Boulevard Niels Bohr, 69100 Villeurbanne, France
- **Room**: Amphitheater Claude Shannon
- **Format**: In-person only (limited to 30 participants)

### Prerequisites
- Basic programming experience (Python preferred)
- Familiarity with IoT concepts
- Laptop with development environment setup (instructions provided)

## Learning Objectives

By the end of this workshop, participants will be able to:
- Set up a complete digital twin development environment
- Implement basic sensor data collection and processing
- Create simple physics-based models
- Integrate real-time data with simulation models
- Deploy a working digital twin prototype

## Workshop Agenda

### Morning Session (9:00 AM - 12:30 PM)

#### 9:00-9:30: Welcome and Setup
- Introduction and objectives
- Development environment verification
- Tool installation and configuration

#### 9:30-10:45: Digital Twin Fundamentals
- Core concepts and architecture patterns
- Open source ecosystem overview
- Hands-on: Setting up the base framework

#### 10:45-11:00: Coffee Break

#### 11:00-12:30: Data Collection and Processing
- IoT sensor integration
- Data preprocessing and validation
- Hands-on: Implementing data pipelines

### Afternoon Session (1:30 PM - 5:00 PM)

#### 1:30-2:45: Model Development
- Physics-based modeling approaches
- Model calibration and validation
- Hands-on: Building simulation models

#### 2:45-3:00: Coffee Break

#### 3:00-4:15: Integration and Synchronization
- Real-time data integration
- Model-data synchronization techniques
- Hands-on: Connecting models to live data

#### 4:15-5:00: Deployment and Wrap-up
- Deployment strategies and best practices
- Project presentations and discussion
- Next steps and resources

# Research Seminar: Uncertainty Quantification in Digital Twin Models

## Seminar Overview

This research seminar explores cutting-edge approaches to uncertainty quantification in digital twin models, addressing one of the most critical challenges in digital twin reliability and trustworthiness.

## Event Details

### Date and Time
- **Date**: March 15, 2024
- **Time**: 2:00 PM - 4:00 PM CET
- **Duration**: 2 hours (including Q&A)

### Format
- **Type**: Virtual seminar via Zoom
- **Registration**: Required (free of charge)
- **Recording**: Available to registered participants
- **Language**: English with French Q&A support

### Target Audience
- Researchers in digital twin technology
- PhD students and postdocs
- Industry practitioners working with model uncertainty
- Anyone interested in reliability engineering

## Program

### 2:00-2:10 PM: Welcome and Introduction
**Host**: Prof. Catherine Dubois, EDT Program Director

### 2:10-2:50 PM: Keynote Presentation
**Speaker**: Prof. Michael Thompson, University of Cambridge  
**Title**: "Bayesian Approaches to Uncertainty Propagation in Multi-Fidelity Digital Twins"

#### Abstract
This presentation explores how Bayesian methods can be applied to quantify and propagate uncertainty through complex digital twin systems. We discuss theoretical foundations, practical implementation challenges, and demonstrate applications in aerospace and automotive industries.

#### Key Topics
- Bayesian inference for model calibration
- Uncertainty propagation in model hierarchies
- Multi-fidelity uncertainty quantification
- Industrial case studies and validation

### 2:50-3:00 PM: Short Break

### 3:00-3:30 PM: Research Presentation
**Speaker**: Dr. Elena Rodriguez, Technical University of Munich  
**Title**: "Machine Learning Approaches to Uncertainty Estimation in Data-Driven Digital Twins"

#### Abstract
We present novel machine learning techniques for estimating uncertainty in data-driven components of digital twin systems. Our approach combines ensemble methods with conformal prediction to provide reliable uncertainty bounds for real-time applications.

### 3:30-4:00 PM: Panel Discussion and Q&A
**Moderator**: Dr. Jean-Pierre Martin, Inria  
**Panelists**: 
- Prof. Michael Thompson (University of Cambridge)
- Dr. Elena Rodriguez (Technical University of Munich)
- Dr. Sarah Kim (Siemens Research)
- Prof. Alessandro Rossi (Politecnico di Milano)

#### Discussion Topics
- Current challenges in uncertainty quantification
- Integration of UQ methods in industrial applications
- Future research directions and opportunities
- Best practices for practitioners

## Event Formatting Guidelines

### Essential Elements
1. **Complete frontmatter** with accurate dates and location
2. **Clear event description** for different audiences
3. **Detailed logistics** (time, location, registration)
4. **Program structure** with speakers and topics
5. **Contact information** for inquiries

### Content Best Practices
- Provide comprehensive event information
- Include speaker bios and credentials
- Specify target audience and prerequisites
- Offer multiple ways to participate when possible
- Include follow-up resources and opportunities

### Accessibility Considerations
- Specify accessibility accommodations available
- Provide multiple contact methods
- Include technical requirements for virtual events
- Offer materials in accessible formats
- Consider time zones for international audiences
