# Documentation index

The `docs/` folder is now split to help two main audiences:

- `docs/developers/` — Technical documentation for developers: CI/CD, analytics, performance, integrations, and troubleshooting that require code changes.
- `docs/editors/` — Content editor documentation: templates, quick references, guidelines, and how-to guides for publishing content.

If you are a developer, start in `docs/developers/`.
If you are creating or editing content, start in `docs/editors/`.

This README will be kept minimal — see the subfolders for full documentation.
