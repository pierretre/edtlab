# Advanced Page Title

This template demonstrates how to use MDX components for rich, interactive content.

## Images and Media

Use the OptimizedFigure component for all images to ensure accessibility and responsive design:

<OptimizedFigure 
  src="image-filename.jpg"
  alt="Descriptive alt text for accessibility"
  caption="Optional caption that provides additional context about the image"
/>

### Image Guidelines
- Always include descriptive `alt` text
- Use meaningful filenames
- Provide captions when they add value
- Images should be placed in `src/assets/images/` or `public/`

## Dynamic Content Lists

### Recent Events
Display events dynamically using the EventList component:

<EventList 
  limit={3}
  showType={true}
  lang="en"
/>

### Publications
Show publications with filtering options:

<PublicationList 
  limit={5}
  showFilters={true}
  defaultType="all"
  defaultYear="all"
/>

### Job Opportunities
Display current job offers:

<JobOfferList 
  limit={3}
  showProject={true}
  lang="en"
/>

<details>

## Accessibility Considerations

- All images must have descriptive alt text
- Use proper heading hierarchy (H1 → H2 → H3)
- Ensure sufficient color contrast
- Provide text alternatives for visual content
- Test with keyboard navigation

## Performance Notes

- Components are loaded only when needed (Astro islands)
- Images are automatically optimized
- CSS is scoped to prevent conflicts
- JavaScript is minimal and progressive
