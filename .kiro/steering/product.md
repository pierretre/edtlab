# Product Overview

This is a multilingual research website platform built with Astro.js. The site supports English and French content and appears to be designed for showcasing research programs, focused projects, publications, and news.

## Key Features

- Bilingual content management (English/French)
- Research program documentation
- Project showcases with structured content
- News and events publishing
- Navigation menu system with hierarchical structure
- Table of contents generation for long-form content

## Content Types

- **Program information**: Goals, structure, committee details, partners
- **Focused projects**: Individual project pages (FP1-FP5)
- **Production**: Publications and platform documentation  
- **News**: Events, press releases, and announcements
- **Static pages**: About, contact, resources, demo center

The platform uses a content-driven approach with markdown files organized by language and content type.
