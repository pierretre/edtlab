## Overview

By its very nature, a digital twin strongly relies on data visualization and user interactions. Indeed, a DT usually embeds interactive systems that enable users to visualize and interact with both the physical and digital twins and their large amount of associated data.

Those interactive systems can take multiple forms, from fully digital VR immersive systems to hybrid AR systems, but also 2D graphical user interfaces, and systems that imply physical input devices. They often propose collaborative asymmetrical (AV/VR/2D) interactive situations, which can also be a challenge.

Building such interactive systems from scratch or without automation is time-consuming and may prevent the generalization of DT as industrial tools. First, novel approaches are required to build the visual representation of the DT, which can be 3D models (to build, for example, by combining CAD models, 3D scans, pictures, and other media sources) or 2D various kinds of information. Users can then interactively finalize some parts of the DT. Additional visualization tools can also help reduce the bias of automatic reconstruction.

Then, DT come with usages that raise research questions regarding, from an HCI viewpoint, how to help users in visualizing data and interacting with it, especially when we use 3D. The visualization concerns not only the "raw" model of the physical twin but also all the data that can be used to enrich the model (additional information about how to use it). It raises new challenges about how to display large datasets of information and how and when to interact with them.

Finally, all these points require validations, at different scales. To reduce the cost of developing the HCI facets of DT, the project must propose novel techniques that focus on their engineering.

The project focuses on 3D reconstruction, data visualization, interaction engineering, spatio-temporal navigation, and validation with clear objectives: developing semi-automatic construction techniques, creating visualization metaphors, designing interaction approaches, implementing seamless transitions, and establishing usability assessment methods.

## Associated Use Cases

Use cases in **PC5** span multiple scales:

- **Territory Scale**: Reconstructing the DT of a city or area and populating it with virtual humans to better understand current limitations and how the DT can enhance it
- **Building/Factory Scale**: Reconstructing the DT of a reconfigurable assembly line, providing AR augmentation for workers and VR visualization for experts who can help remotely
- **Technical Object Scale**: Reconstructing the DT of a complex system (car, satellite) to train people for maintenance tasks using VR interactions, then using AR augmentations when physically in front of the physical twin

## Project Implementation

The project is structured into **five complementary work packages**, addressing reconstruction, visualization, interaction, transitions, and validation.

<details>
<summary><h3>Workpackage1: DT Digital Representation/Reconstruction and Design</h3></summary>

**Leader:** Univ. Bourgogne  
**Partners:** LIST (CEA), ILDA (Inria), Aviz (Inria), INUIT (IMT)

**Objectives:**
- Develop **semi-automatic techniques** for 2D/3D construction of digital twin views
- Handle **3D reconstruction** including AR viewpoint computation
- Manage **2D reconstruction** with multi-view visualization and data fusion

**Key Tasks:**
1. 3D reconstruction including AR viewpoint computation
2. 2D reconstruction with multi-view visualization and error correction
3. Multi-source data integration and fusion
4. Earth DT reconstruction and visualization (with CNES collaboration)

</details>

<details>
<summary><h3>Workpackage2: DT Visualization Augmentations</h3></summary>

**Leader:** Aviz (Inria)  
**Partners:** ILDA (Inria), Hybrid (Inria), INUIT (IMT), ELIPSE (Univ. Toulouse 3), G-SCOP (UGA-INP), Sorbonne University

**Objectives:**
- Create **visualization metaphors** to augment DT content understanding
- Provide enriched visualization of **large datasets** in 2D/3D, AR and VR
- Enhance **collaboration** including avatar systems

**Key Tasks:**
1. Develop enriched visualization for large datasets
2. Implement collaboration enhancement including avatars
3. Create human body models for surgical intervention preparation
4. Design immersive analytics for complex data exploration

</details>

<details>
<summary><h3>Workpackage3: DT Interaction Design and Engineering</h3></summary>

**Leader:** ILDA (Inria)  
**Partners:** ICS (Univ. Toulouse Capitole), ELIPSE (Univ. Toulouse 3), CRTD (CNAM), UMMISCO (IRD), LAMIH (UPHF)

**Objectives:**
- Design **approaches** for describing and generating user interactions with DTs
- Implement **interaction engineering** including tangible user interfaces
- Enable **co-engineering** between multiple stakeholders

**Key Tasks:**
1. Develop interaction engineering frameworks including tangible interfaces
2. Create co-engineering methodologies for multiple stakeholders
3. Implement interaction narration and evolution management
4. Design multi-modal interaction systems

</details>

<details>
<summary><h3>Workpackage4: DT Transitions Engineering</h3></summary>

**Leader:** DiverSE (Univ. Rennes/Inria)  
**Partners:** INUIT (IMT), ILDA (Inria), Hybrid (Inria), ELIPSE (Univ. Toulouse 3), CEA Tech Occitanie, LIST (CEA)

**Objectives:**
- Implement **spatio-temporal transitions** between different DT views
- Enable **solution space transitions** for different configurations
- Create **media transitions** (AR to VR to 2D) for seamless experience

**Key Tasks:**
1. Develop solution space transitions for DT configurations
2. Implement spatial (3D) transitions for navigation and exploration
3. Create media transitions for seamless user experience
4. Ensure cross-platform interaction continuity

</details>

<details>
<summary><h3>Workpackage5: DT Interactive Validation & Verification</h3></summary>

**Leader:** LIST (CEA)  
**Partners:** VirtUs (Inria), Hybrid (Inria), UMMISCO (IRD)

**Objectives:**
- Establish **usability assessment** methods for digital twin interfaces
- Conduct **ergonomics** evaluation for individual users
- Perform **group-scale validation** for collaborative environments

**Key Tasks:**
1. Develop usability assessment at individual user scale
2. Create group-scale validation for collaborative environments
3. Implement VR front-end testing for useful and usable DT interfaces
4. Optimize user experience across different interaction modalities

</details>
